Export bootable ISO (USB re-imaging)

Build a bootable ISO of this image to write to a USB stick with Rufus, then re-image machines whose disk is too small to stage the media locally. Windows installs to the whole internal disk with a temporary name; the agent enrols on first boot and the machine is renamed to its binding's name automatically. Before wiping anything the USB checks the target disk is not the USB stick itself, and powers off instead if it is. The exported ISO carries the answer file — treat it as sensitive.

Write it with Rufus in ISO mode (partition scheme GPT, target UEFI; choose "ISO Image mode" if Rufus asks) and untick every option in Rufus's "Customize Windows installation" dialog — the ISO's own answer file already handles Setup. Raw "DD image" writers (dd, balenaEtcher, Rufus DD mode) produce a stick that will not boot. Boot the target in UEFI mode.
