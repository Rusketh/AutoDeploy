How AutoDeploy uses these settings

When a machine asks for its deployment and its answer file joins a domain, AutoDeploy first deletes any old computer account with that name and creates a fresh one in the right OU — so the machine's first boot into Windows finds the account where it expects it.

Changes apply to the next deployment; no restart needed.
