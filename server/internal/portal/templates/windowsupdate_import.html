Search the Microsoft Update Catalog

Search catalog.update.microsoft.com by KB number or keywords (e.g. KB5034122 or 2024-01 cumulative windows 11 x64), then import a result. The server downloads the file from Microsoft and fills in the update's KB, title, OS filter, and payload — the same record you'd get by creating it manually and uploading the .msu yourself. Only the first 25 catalog results are shown.
