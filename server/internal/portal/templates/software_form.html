  • Absolute paths like C:\Program Files\Acme\foo.exe -- used verbatim.

  • %pkgdir% -- the package work directory the files were downloaded into. Works in any field of any step (args too), e.g. /configure %pkgdir%\config.xml. Steps already run with this as their working directory, so a plain relative arg like config.xml works as well.
