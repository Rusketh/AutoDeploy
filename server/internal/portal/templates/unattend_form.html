8. Computer naming
Placeholders (case-insensitive):
  • %random(N)% — N random characters (default 6), e.g. LAB-%random(4)% → LAB-7K2Q
  • %serial% / %serial(N)% — SMBIOS serial, or its last N characters
  • %uuid% / %uuid(N)% — SMBIOS UUID (hyphens removed), or its last N
  • %agent% / %agent(N)% — the AutoDeploy machine ID
A specific machine's name (set on its inventory page) overrides this template.
