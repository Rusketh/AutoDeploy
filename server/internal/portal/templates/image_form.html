Active Directory domain join (via agent)

The agent joins the domain once the OS is up (networking + DNS available), which is far more reliable than the unattend's online join during Setup. {{$sl := .Data.SetupLock}}
Setup lockout screen

While the agent installs this image's software after first boot, a branded full-screen setup screen replaces the Windows logon screen on every display, showing a progress bar and the current activity (e.g. “Installing Microsoft Office”). Normal sign-in is blocked until the machine is ready for first use. A technician can dismiss it using the global Access PIN (press Ctrl+Alt+U). This applies to the initial deployment only — later app pushes never lock an already-provisioned machine.
