Search the winget community source

Search the winget community catalog (e.g. 7zip, Notepad++, Visual Studio Code), then import an app. The server downloads the app's real installer (and any prerequisites it declares) and builds a standard software package — files, detection, and install steps — that you can edit like any other. Because the installer is captured up front, it installs even where the Microsoft Store / winget source is disabled by policy.

Store-exclusive apps (the msstore source) are licence-locked and can't be repackaged offline — those aren't importable here.
