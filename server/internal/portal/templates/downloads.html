Drop the agent / Boot Client / installer binaries you want to distribute into {{.Data.Dir}} and they'll appear here. Recommended filenames so the portal can group and label them:

  • autodeploy-agent-windows-amd64.exe — Windows deploy agent (in-OS).
  • autodeploy-agent-windows-arm64.exe — same, ARM64.
  • autodeploy-boot-linux-amd64 — Boot Client (Linux, pre-OS).
  • autodeploy-server-linux-amd64 — server binary for fresh installs.

The install scripts in scripts/install-linux.sh and scripts/windows/install-windows.ps1 drop whatever they find in the release bundle into this directory automatically.

Usage notes

The Windows agent is normally installed during PXE deploy through the unattend's first-logon command; download it here when you need to:

  • Bring an existing machine under management — copy the .exe to C:\Windows\AutoDeploy\ and run it once with --server <portal URL> --image-id 0 --check-in 5m.
  • Recover a broken install — re-run the agent after restoring a machine from backup so it re-registers in inventory.
  • Test locally — point the agent at a dev portal with --insecure-tls for self-signed certs.
