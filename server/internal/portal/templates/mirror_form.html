Setup checklist

  1. Stand up the mirror host (any HTTP server that serves the path tree below). Suitable options: a nginx / apache reverse proxy in front of an rsync'd copy of $AUTODEPLOY_DATA_DIR, a Squid configured as a pull-through cache, or a second autodeploy-server instance pointed at a synced data dir.
  2. Make sure the mirror responds to GET /payload/iso/<id>/<path>, GET /payload/drivers/<id> and GET /payload/software/<id> with the same bytes the primary serves.
  3. HTTPS is recommended. The Boot Client will accept the mirror's certificate via its system trust store.
  4. Configure DHCP option 175 (or your iPXE script) on the site's subnet to set autodeploy.site=<site> on the kernel cmdline so the Boot Client passes it in the X-AutoDeploy-Site header.
