Quick start

  1. Upload an ISO and extract it.
  2. Create an Unattend (locale, accounts, OOBE, optional domain join).
  3. Add driver packages with SMBIOS filters for the hardware in scope.
  4. Define software packages with detection rules and install steps.
  5. Group packages into loadouts (optional).
  6. Compose an Image that links them all.
  7. PXE-boot a target machine, then bind it.
