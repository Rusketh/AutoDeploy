Welcome

This is the AutoDeploy management portal (Phase 1). Use the navigation above to browse and manage the standalone artifact objects (ISO, Unattend, Driver package, Software package) and compose them into images.

For each shared object you will see how many images reference it before you edit or delete it. Each image shows its resolved configuration so you can verify what would actually be deployed.

Phase 1 CRUD is exposed via the JSON API at /api/v1/…; curl recipes are in docs/user-guide/api-quickstart.md.
